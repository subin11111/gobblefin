# GOBBLEFIN

작은 물고기를 먹고 성장해 바다의 최강자가 되는 실시간 경쟁형 웹 아케이드 게임입니다. 별도 설치 없이 브라우저에서 바로 플레이할 수 있습니다.

**플레이:** https://gobblefin-reef-arena.hazy-skink-6279.chatgpt.site

## 플레이 방법

- 마우스 또는 터치: 이동 방향 조종
- 클릭을 누른 채 이동 또는 `Space`: 대시 (점수를 조금 소모)
- `P` 또는 `Esc`: 일시정지
- 나보다 작은 물고기는 먹고, 큰 물고기는 피하세요.
- 보물상자를 먹거나 라운드 순위 보상을 받아 코인을 모으세요.
- 상점에서 실제 어종에 착안한 물고기 디자인을 구매할 수 있습니다.

## 로컬 실행

정적 웹사이트이므로 `dist/index.html`을 열거나 원하는 정적 파일 서버로 `dist` 폴더를 제공하면 됩니다.

## 구성

- 닉네임 기반 실시간 멀티플레이와 접속자 표시
- Canvas 기반 게임 루프와 서버 충돌 판정
- 먹은 점수에 비례하는 부드러운 선형 성장
- 경쟁자 AI, 성장·대시·실시간 랭킹 시스템
- 순위·보물상자 코인과 6종 물고기 디자인 상점
- 데스크톱/모바일 터치 대응
- 최고 점수 브라우저 저장
